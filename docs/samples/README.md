# Sample outputs

One file per tool, showing the real shape of its output. Every value here is
fabricated - a fictional tenant ("Northwind Traders"), fictional devices,
fictional group and policy names. Nothing in this folder came from a real
Intune tenant.

The journey tools produce a self-contained HTML report; open one directly in
a browser. The other tools produce a workbook; open in Excel or any
spreadsheet application.

| File | Tool |
|---|---|
| `sample-windows-device-journey.html` | Windows device journey |
| `sample-ios-ipados-journey.html` | iOS/iPadOS device journey |
| `sample-macos-journey.html` | macOS device journey |
| `sample-android-journey.html` | Android device journey |
| `sample-assignment-inventory.xlsx` | Assignment inventory |
| `sample-orphaned-and-unassigned.xlsx` | Orphaned and unassigned |
| `sample-recover-scripts.xlsx` | Recover scripts |
| `sample-change-history.xlsx` | Change history |
